# 3차 과제 — Next.js + FastAPI Todo 앱

2차 과제(React + localStorage)를 **Next.js(App Router) 프론트엔드 + FastAPI 백엔드** 풀스택 구조로 마이그레이션한 Todo 앱입니다.

> 설계/배경은 [`../docs/migration-plan-3.md`](../docs/migration-plan-3.md) 참고.

## 구조

```
assignment-3/
├── frontend/   # Next.js (App Router, TypeScript, Tailwind v4, Axios)
└── backend/    # FastAPI (Uvicorn, SQLAlchemy, SQLite, Pydantic v2)
```
